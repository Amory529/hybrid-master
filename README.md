# 杂交大师 · Hybrid Master

把可遗传的角色特征转成可检查的外观规格：一个 AI 游戏黑客松项目的基因原型与设计记录。

本仓库提供 **Python 离线遗传参考实现、13 条角色资产元数据、设计方案和历史 MVP 文档**。原型输出后代基因与外观计划；游戏接入、在线模型生成和可玩性验证仍待完成。

## 核心想法

玩家选择两只亲本，系统先确定后代继承了哪些基因，再决定本代显示哪些特征，最后将外观规格交给生成环节。

设计目标是保留一个主体轮廓、一套完整表情，并借入另一方少量鲜明特征。隐藏或暂不显示的基因继续保存，供下一代继承。当前参考实现并不保证每次都有明显双亲效果，会标记需要人工检查的结果。

```text
亲本基因 → 遗传取样 → 显隐与兼容规则 → 后代基因 + 外观计划
                                               ↓
                                参考图 / 3D 生成 / 游戏验收（待接入）
```

## 运行离线示例

需要 Python 3，仅使用标准库，无需安装第三方依赖。此次发布在 Python 3.12.14 上核验。

在仓库根目录运行：

```bash
python3 genetics/recombination_reference.py
```

运行将执行已有检查及 4096 次二代遗传模拟，并重写 `genetics/simulation_report.json` 和 `genetics/offspring_examples.json`。此脚本没有网络调用，不需要 API Key，不生成图片或 GLB。

## 已验证的范围

- 固定种子可复现；交换亲本顺序得到相同结果。
- 子代等位基因来自亲本；被遮蔽的基因仍保留。
- 示例显隐规则中，隐性绿色可以在二代重新出现。
- 球体缺少握持位置时隐藏刀盾，但不删除对应基因。

4096 次示例模拟结果：黄色 3019，绿色 1077（约 26.29%）。这是对所实现游戏规则的离线检查，不能证明 3D 神似、游戏性能或真实生物遗传规律。

## 项目记录

本项目由团队协作推进，AI 参与了文档、代码和资产实验。此仓库用于记录黑客松中的设计与参考实现，不将其表述为某位成员独立完成的完整游戏。早期文档里的 A—E 是历史任务占位标识，不是最终成员署名。

目前未提供完整游戏工程、在线试玩、Tripo 成功接入证据或用户增长数据。不同阶段的 100 位、32 槽和 v2 性状设计保留为历史演进，不应混为一套已上线规则。

## 素材范围

仓库只附代码、文字和结构化元数据。原始模型、角色参考图、二维码海报及聊天记录不包含在本版中。元数据里的角色名称和模型文件名用于说明历史实验对象，不表示附带这些素材或统一授予素材使用许可。

使用范围见 [NOTICE.md](NOTICE.md)。
