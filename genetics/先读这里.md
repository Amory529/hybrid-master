# 基因系统公开版阅读指引

此目录整理自 2026-09-24 的基因系统交接包。先看 **PETS_GENE_TABLE.md**，其中有 13 个模型的历史审查元数据，后半部保留旧表。再看 **基因重组实现方案.md**，其中有继承规则、生成流程、三个具体配方和建议落地顺序。当前状态以仓库首页和 `docs/STATUS.md` 为准。

最重要的四点：

1. 一个后代保留一个身体轮廓、一套表情，再借入另一方一至两个识别点。
2. 基因由游戏决定，Tripo 不负责抽基因，只负责按外观规格生成。
3. 没显示不等于没遗传；隐藏基因要继续存着。
4. 脸部红晕、爱心眼、猫脸纹理和黑白花纹不能随全身改色一起覆盖。

## 文件

- `PETS_GENE_TABLE.md`：扩充后的主表。
- `基因重组实现方案.md`：产品与开发实现方案（默认数值均为建议）。
- `gene_assets_v2.json`：13 只资产的性状草案、识别锚点、实际文件信息。
- `asset_inventory.json`：实际 GLB 的 SHA-256、面数、尺寸、材质和贴图统计。
- `recombination_reference.py`：离线遗传参考实现；不是游戏插件，不调用 Tripo。
- `simulation_report.json`：离线验证结果。
- `offspring_examples.json`：3 组实际模拟生成的基因和外观计划，不是已生成的 3D。

原始 GLB、参考图片、`Character_*_audit.png` 审查预览及单独旧表备份未随公开版提供。资产文件名仅用于关联历史记录。

运行参考实现需 Python 3，命令为 `python3 recombination_reference.py`；会重写同目录的模拟结果，不访问网络、不产生 API 费用。

本原型尚未接入游戏，尚未测试 Tripo 杂交神似与生成耗时。9 月 24 日原始审查中的待办包括：牛和无脖子西装老头未在当时审查目录，红发色需要显式祖代或变异规则，Fenxiang 的名称待确认。这些记录不证明其他目录或之后版本的状态。
